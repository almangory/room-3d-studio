# استوديو تنسيق المنازل والأثاث ثلاثي الأبعاد | 3D Multi-Room House Planner

استوديو ويب هندسي تفاعلي ثلاثي الأبعاد (3D) لتخطيط وتنسيق المنازل والغرف المتجاورة وتوزيع قطع الأثاث بمقاسات حقيقية بالسنتيمتر (cm).

## 🌟 المميزات الرئيسية
- 🏡 **تخطيط الغرف المتجاورة (Multi-Room Builder):** إمكانية بناء وإلحاق غرف جديدة متلاصقة لكامل المنزل (شقق سكنية وفلل) والتنقل بينها بنقرة واحدة.
- 📐 **أبعاد ومقاسات دقيقة بالسنتيمتر:** تعديل حي للعرض، العمق، الارتفاع، والارتفاع عن الأرض، مع حساب المسافات الصافية الحية عن الحوائط (Clearance Distances).
- 🛋️ **كتالوج أثاث ومعمارية موسع (49+ عنصر):** غرف معيشة، غرف نوم، مطابخ وحمامات، سفرة ومكتب، وأبواب ونوافذ ومعمارية.
- 🔄 **نظام تراجع وإعادة متكامل (Undo / Redo):** دعم كامل لاختصارات `Ctrl+Z` و `Ctrl+Y` وسجل تاريخي للتعديلات.
- 💾 **حفظ واستيراد مرن + حفظ تلقائي (Auto-Save):** تصدير واستيراد ملفات المشاريع بصيغة JSON مع التوافق التام مع الإصدارات السابقة (v1.0 و v2.0)، وحفظ تلقائي فوري في المتصفح.
- ☀️ **إضاءة متغيرة:** تبديل بين النمط النهاري والمسائي، وعرض مسقط أفقي 2D أو منظور ثلاثي الأبعاد 3D.
- 📱 **واجهة عربية متجاوبة بالكامل (RTL):** مبنية بأحدث معايير الويب وخط تجوال العربي الأنيق.

## 🚀 التقنيات المستخدمة
- **Three.js (WebGL)** لمحاكاة المشهد ثلاثي الأبعاد والتحكم بالكاميرا
- **Tailwind CSS** للتصميم العصري ودعم الوضع الليلي
- **JavaScript (Vanilla ES6+)** لأداء فائق السرعة وخفة في التشغيل
- **Cloudflare Workers Assets** للنشر السحابي السريع على حافة الشبكة العالمية

## 🛠️ التشغيل المحلي
يمكن تشغيل المشروع مباشرة بفتح ملف `index.html` في أي متصفح حديث، أو عبر أي خادم ويب محلي:
```bash
npx serve .
# أو
python -m http.server 8000
```
